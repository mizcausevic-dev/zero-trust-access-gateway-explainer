## What this is

An educational schematic. Play, scrub, or jump the five stages. The same frame always draws the same picture. The page does not collect data, set cookies, or load third-party code.

## What this is not

Zero trust is an architecture, not one appliance, and not a promise that breaches cannot happen. This drawing is one gateway-style policy enforcement point. It is not a NIST figure and not a vendor console.

Mechanism reference: NIST Special Publication 800-207, *Zero Trust Architecture*, August 2020. https://doi.org/10.6028/NIST.SP.800-207

Cyan is the data plane. Violet is the control plane. Gold is the gate being commanded. Those colors are labels, not a seven-theme dashboard.
